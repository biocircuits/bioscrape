Flexible Model Specification, Fast Simulation, and Bayesian Parameter Inference for Biological Circuits
=======================================================================================================

The bioscrape package is a Python package for doing the types of
modeling and computational tasks that are commonly required for
scientists and researchers working in the field of systems biology or
synthetic biology. It can be somewhat framed a Python alternative to
MATLAB's SimBiology, though there are some features in the package that
are not available in SimBiology (Bayesian parameter inference, many
features of stochastic simulation, and support for delays), and a great
number of features in SimBiology that are not part of the package. For
installation, usage, examples, and other information, please use the
links below. You can access the code from the repository by clicking on
the link above. For citing, please see the references below.
